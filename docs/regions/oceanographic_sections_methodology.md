\# NZ OISST Coastal Oceanographic Sections v2



\## Purpose



Create reproducible coastal monitoring sections for aggregating NOAA

OISST sea-surface temperature, anomalies and marine heat events around

mainland New Zealand and Stewart Island.



\## Unit of classification



The classification unit is the centre of each valid NOAA OISST 0.25-degree

ocean grid cell.



\## Geographic scope



\- North Island

\- South Island

\- Stewart Island / Rakiura

\- Coastal ocean surrounding these islands

\- Remote island groups excluded from version 2



\## Design principles



1\. Every included OISST grid cell belongs to exactly one region.

2\. Regions must be spatially contiguous.

3\. Regions must represent similar historical SST behaviour.

4\. Boundaries must use whole OISST cells.

5\. Regions must contain enough cells to support stable daily averages.

6\. Administrative land boundaries will not determine marine boundaries.

7\. Existing New Zealand marine classifications and major current systems

&#x20;  will be used for scientific validation.

8\. The method and inputs must be reproducible.
